The projects on the resume, each written so that every claim can be defended in an
interview: what was asked, what was built, every number with the file or run it comes from,
and the questions an interviewer is likely to ask. MTP and Transformer are built from the same
LaTeX sources as the PDFs; the GPU section is written directly.
