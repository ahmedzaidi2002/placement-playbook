### 1 · Q11-15, microprocessor passage

*Asked by: Accenture (IDC paper); Accenture (Dec paper)*

(Passage summarised at the start of the chapter.)
(11) Which description would NOT fit a microprocessor? [electronic computer / CPU / memory
disk / a single integrated circuit] (12) Which is TRUE? [microprocessors and computers on a
chip are variations of each other / integration of processing on chips made processing power
cheaper / before microprocessors, CPUs were not made from small-scale ICs / a microprocessor
circuit has only transistors] (13) Which was NOT among the first to develop a microprocessor?
[Microsoft / Intel / Texas Instruments / Garrett] (14) Which is NOT a use of microprocessors
according to the passage? [drivers for calculators / core of large mainframes / advanced
mobile phones / small handheld computers] (15) "A number of microprocessors as its CPU"
describes a: [micro-controller / micro-computer / micro-processor / micro-transistor]

{{< details title="Answer and explanation" closed="true" >}}

**Answers: (11) memory disk (12) integration made processing power cheaper (13) Microsoft (14) advanced mobile phones (15) micro-computer**

**Why.** (11) A microprocessor is a CPU on a single chip; a memory disk is storage. (12) The passage says putting processing on chips cut its cost. (13) Intel, Texas Instruments and Garrett are named as early developers; Microsoft made software. (14) Mobile phones are not mentioned. (15) A computer using microprocessors as its CPU is a micro-computer.

**Concept: answer from the passage, not general knowledge.** "According to the passage" questions reward matching the text. "NOT" questions: eliminate the three options the passage supports.

### 2 · Q16-20, DLL passage

*Asked by: Accenture (IDC paper)*

(Passage summarised at the start of the chapter.)
(16) By using DLLs, Windows: [saves processing time / multitasks / shares program code /
communicates with the hardware] (17) To use a DLL routine, Windows: [copies it into the
application / loads the DLL file and searches and executes the routine / loads just the
required routine / tells the application to execute it] (18) What must the application pass
to Windows? [the routine name / the DLL name / routine, DLL and parameters / DLL, routine,
parameters and type of information to be returned] (19) While the DLL routine executes, the
calling application: [waits / continues with other tasks / helps the DLL talk to Windows /
passes all responsibility to the DLL and is removed from memory] (20) After execution the
DLL function returns: [the parameters and information into memory / information into memory
where the calling application can inspect it / the information directly to the application /
information so that the DLL can inspect it]

{{< details title="Answer and explanation" closed="true" >}}

**Answers: (16) shares program code (17) loads the DLL file and executes the routine (18) the DLL name, routine, parameters and type of result (19) waits (20) information into memory, where the calling application inspects it**

**Why.** The passage explains that DLLs let programs share code; Windows loads the specific DLL into memory and runs the routine; the program passes the DLL name, the routine, its parameters and the type of result it expects; it waits while the routine runs; the result is placed in memory for the program to read.

**Concept: dynamic-link libraries.** A DLL is a file of shared functions loaded at run time. Many programs can use one copy, saving memory and disk space, instead of each program carrying its own copy.

### 3 · Q11-16, science-education passage

*Asked by: Accenture (Previous year)*

(Passage summarised at the start of the chapter.) (11) The "professional schoolmaster" has
[no interest in science / thwarted attempts to enliven education / aided true learning /
supported the humanists / pioneered both]. (12) The author's attitude to school science
education is [ambivalent / neutral / supportive / satirical / contemptuous]. (13)
"Palpably" means [empirically / obviously / tentatively / markedly / ridiculously].
(14) The author blames all of these for the failure EXCEPT [poor teaching / examination
methods / lack of direct experience / the social and education systems / lack of interest of
students]. (15) Revisiting today, he would most want to know: [do students know more about the
world / spend more time in labs / can students apply their knowledge logically / have
textbooks improved / do they respect teachers]. (16) Astrology is mentioned as [a science to
be better understood / a belief no educated person holds / something unsupportable to those who
have absorbed scientific method / the gravest danger / a failure of science].

{{< details title="Answer and explanation" closed="true" >}}

**Answers: (11) thwarted attempts to enliven education (12) contemptuous (13) obviously (14) lack of interest of students (15) can students apply their knowledge logically (16) unsupportable to those who have absorbed the methods of science**

**Why.** The author blames the schoolmaster and the system, scorns school science (contemptuous), uses "palpably" to mean obviously, never blames students' interest, values reasoning over facts, and uses astrology as an example of what scientific thinking should reject.

**Concept: tone and vocabulary in context.** Tone words (ambivalent, satirical, contemptuous) describe the author's attitude; look for strong judgement words in the passage. For a word's meaning, replace it in the sentence with each option.

### 4 · Q17-20, Wakefield Master passage

*Asked by: Accenture (Previous year)*

(Passage summarised at the start of the chapter.) (17) Which is NOT true of the Wakefield
Master? [he and Chaucer were contemporaries / he wrote five or six realistic plays / his plays
portray the plight of country folk / his writing was similar to Steinbeck's / he was an
accomplished artist] (18) "Patristic" means [patriotic / superstitious / folk / relating to
the Christian Fathers / realistic]. (19) "Secularisation of medieval drama" refers to
[religious themes / erudite material / contemporary materials / the return to reverence /
introduction of mundane matters into religious plays]. (20) In the next paragraphs the writer
would [justify the Steinbeck comparison / develop the thought of the second paragraph /
point out anachronisms / discuss Chaucer / discuss the lack of realism].

{{< details title="Answer and explanation" closed="true" >}}

**Answers: (17) the keyed answer is "his writing was similar to Steinbeck's" (the plays only being "attributed" to him is a strong alternative) (18) relating to the Christian Fathers (19) introduction of mundane matters into religious plays (20) develop the thought of the second paragraph**

**Why.** The passage calls him "a kind of medieval Steinbeck" in outlook only; "patristic" refers to the Church Fathers; secularisation means bringing everyday matters into religious drama; the passage ends by setting up its second paragraph's idea.

**Concept: "NOT true" questions.** Each wrong option is something the passage states; the right answer overstates or contradicts the passage. Comparisons ("a kind of X") are not claims of similarity in every respect.

### 5 · Q23, sleep and cognitive performance

*Asked by: EPAM (EPAM freshers test)*

(Reading comprehension; the passage is summarised.) Research links sleep architecture to
cognitive performance: sleep *quality*, such as uninterrupted REM phases, may matter
more than total duration, and individual chronotypes mean people peak at different times
of day. What does the research suggest about sleep and cognitive performance?

- **(a)** Total sleep duration is most important
- **(b)** Sleep quality matters more than sleep quantity
- **(c)** Everyone performs best at the same time
- **(d)** Sleep deprivation has no real effects

{{< details title="Answer and explanation" closed="true" >}}

**Answer: (b) sleep quality matters more than sleep quantity**

**Why.** The passage contrasts quality (uninterrupted REM) with duration. The chronotype point rules out (c); documented effects of sleep loss rule out (d).

**Concept: main idea.** The main claim is usually the one the passage contrasts with a common belief ("quality may matter more than duration").

### 9 · Q16, Kuhn's paradigms

*Asked by: ION Group (SDE OA, Jul 2025)*

Read the paragraph and answer. Thomas Kuhn's work on scientific paradigms challenged the
view of scientific progress as cumulative. Kuhn proposed episodic revolutions, in which
dominant paradigms are overthrown by anomalies they cannot explain. These revolutions are
not purely rational but involve sociological and psychological factors, as scientists
cling to familiar frameworks until contradictions become unbearable. Paradigm shifts are
then less about absolute truth and more about the prevailing consensus within the
community. Critics say this relativism undermines objectivity; defenders say it captures
the messiness of actual scientific practice. According to the passage, what is the
implication of Kuhn's theory for understanding scientific progress?

- **(a)** It validates the notion of universal scientific truth
- **(b)** It emphasizes the linear and rational evolution of science
- **(c)** It confirms the supremacy of modern paradigms over older ones
- **(d)** It suggests that scientific change is contingent and socially influenced

{{< details title="Answer and explanation" closed="true" >}}

**Answer: (d) scientific change is contingent and socially influenced**

**Why.** The passage stresses sociological factors and consensus rather than absolute truth or steady, rational, cumulative progress. That rules out (a), (b) and (c).

**Concept: paradigm shifts (Kuhn).** Kuhn argued science moves through long stable periods broken by revolutions, when a dominant framework collapses under unexplained anomalies; which framework wins depends partly on the scientific community, not only on logic.

### 10 · Q18, conclusion of the billiards argument

*Asked by: MAQ Software (TalentDecrypt test, 2025)*

"People say that playing billiards is the best way to burn calories, but this is not true.
Since playing billiards requires very little physical effort, billiards does not help in
burning many calories." What is the main conclusion?

- **(a)** People say that playing billiards is the best way to burn calories.
- **(b)** Playing billiards is not the best way to burn calories.
- **(c)** Playing billiards does not burn many calories.
- **(d)** Playing billiards requires little physical exertion.

{{< details title="Answer and explanation" closed="true" >}}

**Answer: (b) playing billiards is not the best way to burn calories**

**Why.** The argument exists to reject the popular claim. (d) is the premise (little effort), (c) the step in between (few calories), (b) the main conclusion.

**Concept: premise vs conclusion.** Ask "what is the author trying to prove?" The conclusion is supported by the other statements; "since" marks a premise.

### 13 · D9, gift-giving, psychologists and economists

*Asked by: Siemens Energy (MNNIT Allahabad (Mettl))*

(Reading comprehension, summarised: people spend billions every month on gifts; social
psychologists see gift-giving as a positive social tradition, while economists see it as a
waste of resources, the "deadweight loss" of gifts the recipient would not buy for
themselves.) What does the passage suggest about the relationship between social
psychologists and economists regarding gift-giving?

- **(a)** They collaborate to analyse the economic impact.
- **(b)** They unanimously agree on the benefits.
- **(c)** They jointly advocate for stricter rules during festive seasons.
- **(d)** They diverge in their viewpoints, with economists embracing doubt.

{{< details title="Answer and explanation" closed="true" >}}

**Answer: (d) they diverge in their viewpoints, with economists embracing doubt**

**Why.** Psychologists see gifts as a positive social tradition; economists see a "deadweight loss" (gifts worth less to the receiver than they cost). The passage contrasts these views; nothing supports collaboration or agreement.

**Concept: deadweight loss of gifts.** If you spend ₹1000 on a gift the receiver values at ₹700, ₹300 of value is lost. That is why economists doubt gift-giving's efficiency.

### 17 · reading passage, inference

*Asked by: Wells Fargo (SHL test, Oct 2022)*

What would the author most likely agree with?

- **(a)** People generally do not try to hide the money taken as bribe.
- **(b)** People hide the money taken as bribe primarily to avoid detection.
- **(c)** People hide the money taken as bribe from view even if detection possibility is low.
- **(d)** People hide the money taken as bribe to hide their economic background.

{{< details title="Answer and explanation" closed="true" >}}

**Answer: (c) people hide the money even if detection is unlikely**

**Why.** The passage says people avoid a direct handover "even where there is no chance of detection". (b) is called only "one obvious reason".

**Concept: inference from explicit phrases.** The option repeating a qualified statement from the passage ("even where ...") is safer than one that overstates it ("primarily").
