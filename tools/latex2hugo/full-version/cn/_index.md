This book is everything about computer networks that a placement interview or an online assessment can ask: layering and delays, the physical and data link layers, IP addressing and subnetting, routing, TCP and UDP, the application protocols, network security, and the set-piece interview questions such as what happens when you type a URL. Every subnet, checksum, CRC, window and congestion trace was computed by a program in the book’s code folder, and the box under it is its real output.
