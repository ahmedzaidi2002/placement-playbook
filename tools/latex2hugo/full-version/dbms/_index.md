This book is everything about database management systems and SQL that a placement interview or an online assessment can ask: the relational model and algebra, SQL in depth, functional dependencies and normal forms, transactions, concurrency control, recovery, storage and indexing, query processing, and the distributed and NoSQL topics that system-design rounds touch. Every query was run, and the box under it is the real result; every key, closure, schedule and B$^+$-tree was checked by a script.
